# PuzzleCut AI — frontend

Next.js 16 (App Router) + TypeScript + Tailwind CSS 4 + Three.js. See the repository root `README.md` for setup.

```bash
npm install
npm run dev        # http://localhost:3000 (expects the API on NEXT_PUBLIC_API_URL, default http://localhost:8000)
npm test           # Vitest + Testing Library
npm run build      # production build
```
